# Быстрые ответы по SQL

Адаптивный сайт с поиском по 80 вопросам из PDF SyncShare.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и установка зависимостей не требуются. Данные, стили и JavaScript включены в HTML, поэтому сайт работает без интернета.

## Возможности

- Мгновенный поиск по тексту вопроса, ответам или номеру.
- Одиночный выбор, множественный выбор и сопоставления.
- Просмотр всех вариантов и статистики голосования.
- Копирование вопроса и ответа.
- Адаптация для телефонов.
- Переключатель «Тестирование»: все 80 вопросов в случайном порядке при каждом запуске.
- Мгновенная проверка одиночного ответа; кнопка «Проверить» для нескольких ответов и сопоставлений.
- Показ правильных вариантов после ошибки, итоговый результат и повтор только ошибочных вопросов.

Для одиночного выбора приоритет имеет отметка «Правильно» в источнике. Если её нет, используется наиболее выбранный вариант с предупреждением. Для checkbox выбраны два лидера по голосам «за», включая варианты, равные второму месту. Статистика не гарантирует правильность. В вопросе 5 равенство голосов разрешено по смыслу команды TRUNCATE.

Источник данных: предоставленный PDF SyncShare от 9 октября 2026 года.

Уточнения имеют приоритет над статистикой голосования. В вопросе № 16 правильны NOT NULL, FOREIGN KEY и PRIMARY KEY; это исправление применяется и в поиске, и в тестировании.

В вопросе № 40 правильны NATURAL JOIN, INNER JOIN и JOIN (без INNER). Уточнение также применяется в поиске и тестировании.

В вопросе № 20 правильны Структурная часть, Целостная часть и Манипуляционная часть. Уточнение применяется в поиске и тестировании.

В вопросе № 30 правильны DCL (Data Control Language), DDL (Data Definition Language) и DML (Data Manipulation Language). Уточнение применяется в поиске и тестировании.
