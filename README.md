# Быстрые ответы по SQL

Адаптивный сайт с поиском по 80 вопросам из PDF SyncShare.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и установка зависимостей не требуются. Данные, стили и JavaScript включены в HTML, поэтому сайт работает без интернета.

## Возможности

- Мгновенный поиск по тексту вопроса, ответам или номеру.
- Одиночный выбор, множественный выбор и сопоставления.
- Просмотр всех вариантов и статистики голосования.
- Копирование вопроса и ответа.
- Адаптация для телефонов.

Для одиночного выбора приоритет имеет отметка «Правильно» в источнике. Если её нет, используется наиболее выбранный вариант с предупреждением. Для checkbox выбраны два лидера по голосам «за», включая варианты, равные второму месту. Статистика не гарантирует правильность. В вопросе 5 равенство голосов разрешено по смыслу команды TRUNCATE.

Источник данных: предоставленный PDF SyncShare от 9 октября 2026 года.
